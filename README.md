# 🌙 NexVault Dark

> Multi-chain Crypto Portfolio Dashboard — Dark Edition

![HTML](https://img.shields.io/badge/HTML-5-orange) ![CSS](https://img.shields.io/badge/CSS-3-blue) ![JS](https://img.shields.io/badge/JavaScript-ES6-yellow) ![License](https://img.shields.io/badge/License-MIT-green)

## 🚀 Features

- 🔐 Multi-wallet connect (MetaMask, Phantom, Ledger, WalletConnect, Rabby, Coinbase)
- 📊 Live portfolio charts (Chart.js)
- 🪙 Token tracker with 12 assets
- 🖼️ NFT Gallery (grid + list view)
- 📋 Transaction history with filters & CSV export
- 📈 Analytics — performance vs BTC/ETH, monthly PnL, risk metrics
- 🌐 Multi-chain: Ethereum, Solana, Polygon, BNB, Arbitrum
- ✨ Particle effects, tilt cards, glow animations

## 🛠️ Usage

1. Clone the repo
2. Open `index.html` in browser
3. Internet required (CDN: Chart.js, Lucide icons)
